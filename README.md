# SKSSF Letter Generator\n\nAutomated official letter generation for **SKSSF Valachil Padavu Unit**.\n\nGenerates official letters on the organization's letterhead with signature — powered by AI.\n\n## Features\n\n- **AI Auto-Fill** — Describe the situation in plain text, AI extracts name, address, issue type and drafts a formal letter\n- **AI Fix** — Clean up rough notes into formal letter language with one click\n- **7 Issue Types** — Health, Financial, Education, Marriage, Death Benefit, General, Other (AI custom)\n- **Live Preview** — See the letter as you fill the form\n- **Official Letterhead** — Uses the original scanned letterhead with signature overlay\n- **Mobile Friendly** — Works on phones, tablets, and desktops\n- **Letter History** — Track and re-download previously generated letters\n\n## Quick Start\n\n```bash\npip install -r requirements.txt\nexport MISTRAL_API_KEY=your_key\npython app.py\n# → http://localhost:5050\n```\n\n## Deployment (Render.com)\n\n1. Push this repo to GitHub\n2. Go to [render.com](https://render.com) → New → Web Service → Connect your repo\n3. Set environment variable: `MISTRAL_API_KEY`\n4. Render auto-detects the `render.yaml` — just click Deploy\n\nOr deploy manually:\n- **Build Command:** `pip install -r requirements.txt`\n- **Start Command:** `gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120`\n\n## Environment Variables\n\n| Variable | Description |\n|---|---|\n| `MISTRAL_API_KEY` | Mistral AI API key for the AI parser and fix features |\n| `PORT` | Port to run on (default: 5050, auto-set by Render) |\n\n## API Endpoints\n\n| Route | Method | Description |\n|---|---|---|\n| `/` | GET | Web UI |\n| `/generate` | POST | Generate and download PDF |\n| `/preview` | POST | Generate PDF for inline preview |\n| `/ai_parse` | POST | AI parse raw text → structured fields |\n| `/ai_fix` | POST | AI clean up rough note → formal text |\n| `/issue_types` | GET | List available issue types |\n| `/health` | GET | Health check |\n
